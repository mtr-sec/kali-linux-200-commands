## How to use

1. Start with the first guide and practise each command in order.
2. Use a Kali Linux virtual machine or a system you are authorized to administer.
3. Replace example values such as `file`, `folder`, `username`, `host`, and `PID` with your own values.
4. Read the manual for more detail with `man command` or `command --help`.

## Safety notes

- Understand a command before running it, especially commands that modify or delete data.
- Use `sudo` only when administrator privileges are required.
- Be careful with file deletion, permission changes, disk tools, and service controls.
- Only scan or test systems and networks you own or have explicit permission to assess.
