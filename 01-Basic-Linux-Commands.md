# 01. Navigation & terminal basics

Beginner reference: command, purpose, and a simple example. Examples should be adapted to your own machine or authorized lab.

| # | Command | Purpose | Example |
|---:|---|---|---|
| 1 | `pwd` | Print the current working directory. | `pwd` |
| 2 | `ls` | List files and folders. | `ls` |
| 3 | `ls -l` | List items with details. | `ls -l` |
| 4 | `ls -a` | Include hidden files. | `ls -a` |
| 5 | `ls -lh` | Show file sizes in a readable format. | `ls -lh` |
| 6 | `cd /path` | Move to a specified directory. | `cd /home/kali` |
| 7 | `cd ..` | Move to the parent directory. | `cd ..` |
| 8 | `cd ~` | Move to your home directory. | `cd ~` |
| 9 | `cd -` | Return to the previous directory. | `cd -` |
| 10 | `clear` | Clear the terminal display. | `clear` |
| 11 | `history` | Display previously entered commands. | `history` |
| 12 | `date` | Display the current date and time. | `date` |
| 13 | `cal` | Display a calendar. | `cal` |
| 14 | `whoami` | Display the current username. | `whoami` |
| 15 | `hostname` | Display the computer's hostname. | `hostname` |
